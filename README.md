# Elden Ring Map & Live Progress Tracker

Интерактивная карта высокой четкости и трекер прогресса для **Elden Ring** (включая дополнение **Shadow of the Erdtree**). 

Автоматически синхронизируется с игрой: отслеживает положение персонажа в памяти в реальном времени и отмечает собранный лут при каждом автосохранении игры. Поддерживает оригинальную игру, Seamless Co-op и Item Randomizer.

---

## 🎮 Быстрый запуск для игроков (Без установки Node.js)

1. Перейдите во вкладку **Releases** и скачайте `EldenRingTracker-v1.0.0-Windows.zip`.
2. Распакуйте архив в любое место.
3. Запустите файл `EldenRingTracker.exe`.
4. В открывшемся браузере выберите ваш файл сохранения `ER0000.sl2` (программа автоматически найдет сохранения вашей учетной записи Steam в `%APPDATA%\EldenRing`) и слот персонажа.
5. Готово! Играйте — карта будет обновляться сама.

## 🌟 Ключевые возможности

### ⚡ Живое авто-отслеживание (Live-Sync)
- **Мониторинг процесса игры (Real-Time Memory Tracking)**:
  - Высокоскоростной C# Win32 модуль считывает координаты игрока (`CSMenuMan`), угол обзора, здоровье и текущий уровень/подземелье напрямую из памяти `eldenring.exe`.
  - Золотой маркер игрока на карте плавно перемещается вслед за вашим персонажем в реальном времени (15 кадров/сек с гладкой интерполяцией).
  - Моментальный подхват поднятого лута через срез оперативной памяти флагов (`CSEventMan`) без задержек.
- **Поддержка любых сохранений**:
  - Оригинальные сохранения Steam (`ER0000.sl2` с расшифровкой AES-128-CBC).
  - Seamless Co-op (`.co2`).
  - Item / Enemy Randomizer (`.randobak` + автоматическое чтение спойлер-логов).
- **Мастер выбора персонажа**:
  - Автоматическое обнаружение Steam ID в `%APPDATA%\EldenRing`.
  - Определение всех 10 слотов персонажей с отображением имени, уровня, часов игры и счетчика боссов.

### 🔍 Фильтрация и Маршруты
- Мгновенный поиск на **русском и английском языках**.
- Режим **«Только несобранное»** — скрывает уже найденный лут одним кликом.
- **Route Planner**:
  - Прокладка оптимального маршрута от ближайшей благодати с расчетом азимута и дистанции на Потоке.
  - Режим **Loot Run** (сбор группы предметов с алгоритмом оптимизации пути 2-Opt / TSP).

## 🛠️ Разработка и Сборка из исходников

### Требования
- **Node.js** v18+
- **.NET Framework 4.5+** (встроен в Windows 10/11)

### Команды

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки (Vite Dev Server с горячей перезагрузкой)
npm run dev

# Сборка только фронтенда
npm run build

# Полная сборка релизного пакета (.exe лаунчер + сервер + клиент + zip)
npm run package
```

После выполнения `npm run package` готовый дистрибутив для пользователей появится в папке `release/EldenRingTracker-v1.0.0-Windows.zip`.

## 🔒 Безопасность и Приватность
- Программа работает **строго локально**: расшифровка сохранений и чтение памяти производятся на вашей машине, данные не передаются во внешнюю сеть.
- Чтение памяти игры осуществляется в режиме `PROCESS_VM_READ` (только чтение). Античит Easy Anti-Cheat (EAC) при игре с модами / рандомайзером / Seamless Co-op отключен по умолчанию разработчиками этих модов.
